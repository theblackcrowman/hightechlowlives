# High-Tech Low-Lives

*A Fate Core campaign set in the grimy underbelly of humanity's furthest frontier.*

It's 1995. Japan won the Second World War. Nuclear weapons never worked. Through their own Operation Paperclip, Japan recruited the world's brightest minds and accelerated technology beyond anything the old world expected. Humanity reached the outer planets. **Space Station Ganges** hangs in orbit above Jupiter — overcrowded, corrupt, and teetering on the edge of a gang war.
